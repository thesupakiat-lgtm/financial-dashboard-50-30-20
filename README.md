# Money Flow 50/30/20 – Version 4

Web Dashboard บริหารเงินแบบไฟล์เดียว พร้อมคำนวณงบ 50/30/20 จากเงินเดือนของเดือนที่เลือกโดยอัตโนมัติ

## วิธีคำนวณ

เมื่อบันทึกเงินเดือน ระบบสร้าง **งบเป้าหมาย** ทันที เช่น เงินเดือน 50,000 บาท:

- ค่าใช้จ่ายจำเป็น 50% = 25,000 บาท
- ความสุขส่วนตัว 30% = 15,000 บาท
- การออมและการลงทุน 20% = 10,000 บาท

งบที่คำนวณเป็นเป้าหมายสำหรับเปรียบเทียบกับยอดจริง ระบบจะไม่สร้างรายการรายจ่ายหรือรายการออมปลอมขึ้นมาเอง

รายได้เสริมและโบนัสยังถูกรวมใน “รายรับรวม” และ “เงินคงเหลือ” แต่ไม่รวมเป็นฐานคำนวณ 50/30/20 เพื่อให้แผนยึดตามเงินเดือนตามที่กำหนดไว้

## ฟังก์ชันหลัก

- ใส่หรือแก้ไขเงินเดือนจาก Dashboard ได้โดยตรง
- แสดงตัวอย่าง 50/30/20 แบบสดขณะพิมพ์เงินเดือน
- อัปเดตงบเป้าหมาย ตาราง กราฟ และคำแนะนำทันทีหลังบันทึก
- เพิ่ม แก้ไข และลบรายการรายรับ รายจ่าย เงินออม และการลงทุน
- ปรับสัดส่วนเป้าหมายได้ในหน้า Settings โดยผลรวมต้องเท่ากับ 100%
- สรุปรายเดือนและแนวโน้มรายปี
- Export CSV, Backup JSON, Restore JSON และ Print / Save PDF
- รองรับ Desktop และ Mobile
- เก็บข้อมูลด้วย localStorage ในเบราว์เซอร์
- ไม่มี CDN, Framework, Server หรือฐานข้อมูลภายนอก

## นำขึ้น GitHub Pages

1. อัปโหลด `index.html` และไฟล์อื่นในโฟลเดอร์นี้ไว้ที่ระดับบนสุดของ Repository
2. เปิดใช้งาน GitHub Pages สำหรับ Branch ที่เก็บไฟล์
3. เปิด URL ของเว็บไซต์ แล้วกดรีเฟรชแบบไม่ใช้ Cache หลังอัปเดตไฟล์

ไฟล์ `index.html` เป็นไฟล์แบบ Self-contained จึงสามารถใช้งานได้แม้อัปโหลดเพียงไฟล์เดียว

## อัปเดตจาก Version 3

ใช้ URL GitHub Pages เดิมและเขียนทับ `index.html` ได้ ข้อมูลเดิมยังอยู่เพราะ Version 4 ใช้ localStorage key เดิม อย่างไรก็ตามควรกด `Backup JSON` ก่อนอัปเดตทุกครั้ง
