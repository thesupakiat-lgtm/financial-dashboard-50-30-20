# Monthly Salary + 50/30/20 Finance Dashboard

เว็บแดชบอร์ดแบบ Static สำหรับคำนวณเงินเดือนรายเดือน และส่ง **เงินสุทธิ** ไปวางแผนต่อด้วยสูตร **50/30/20** ได้ในโปรเจกต์เดียว ไม่ต้องมีฐานข้อมูลหรือเซิร์ฟเวอร์หลังบ้าน และนำขึ้น GitHub Pages ได้ทันที

## หน้าที่อยู่ในโปรเจกต์

### 1. `index.html` — Dashboard คำนวณเงินเดือน

- คำนวณเงินได้ต่อวัน ต่อชั่วโมง และต่อนาทีจากเงินเดือนพื้นฐาน
- แยกวันทำงานปกติ วันเสาร์ วันอาทิตย์ และคำนวณ OT ด้วยตัวคูณที่แก้ไขได้
- รองรับค่าทักษะ ค่าเช่าบ้าน ค่าภาษา ค่าน้ำมัน ค่าอาหาร เบี้ยขยัน รายได้อื่น โบนัส Attendance และขายวันลาพักร้อน
- เพิ่ม ลบ เปลี่ยนชื่อ และแก้ไขจำนวนเงินของรายการหักได้โดยตรง
- คำนวณกองทุนสำรองเลี้ยงชีพ ประกันสังคม ลาไม่รับค่าจ้าง และมาสาย
- ไม่มีช่องชื่อ รหัส หรือแผนกพนักงาน
- บันทึกประวัติรายเดือน ส่งออก CSV และสำรอง/นำเข้า JSON
- พิมพ์หรือบันทึกสรุปเงินเดือนเป็น PDF ผ่านคำสั่ง Print ของเบราว์เซอร์

หน้าเงินเดือนมีส่วนสรุป 50/30/20 แบบย่อ โดยคำนวณจากเงินสุทธิทันที:

```text
ค่าใช้จ่ายจำเป็น      = เงินสุทธิ × 50%
ความสุขส่วนตัว       = เงินสุทธิ × 30%
การออมและการลงทุน    = เงินสุทธิ × 20%
```

กดปุ่ม **แผน 50/30/20** หรือ **เปิด Dashboard การเงิน** เพื่อไปยังหน้าวางแผนการเงินฉบับเต็ม

### 2. `finance-50-30-20.html` — Dashboard วางแผนการเงิน

- รับเดือน รายได้รวม รายการหัก และเงินสุทธิจากหน้าคำนวณเงินเดือนอัตโนมัติ
- ใช้เงินสุทธิเป็นฐานแบ่งงบ 50/30/20
- มีหน้า Dashboard, รายการเงิน, สรุปรายเดือน และตั้งค่า
- เพิ่ม แก้ไข ลบ และค้นหารายรับ รายจ่าย เงินออม หรือเงินลงทุนได้
- ปรับสัดส่วนจาก 50/30/20 เป็นสัดส่วนอื่นได้ โดยผลรวมต้องเท่ากับ 100%
- เพิ่มหมวดหมู่และช่องทางชำระเงินได้
- แสดงเป้าหมายเทียบยอดจริง กราฟโครงสร้าง และคำแนะนำอัตโนมัติ
- มีปุ่ม **คำนวณเงินเดือน** ในเมนูเพื่อกลับไปยัง `index.html`

เมื่อกดเข้าหน้าวางแผนซ้ำในเดือนเดิม ระบบจะอัปเดตรายการเงินเดือนสุทธิของเดือนนั้นแทนการสร้างรายการซ้ำ ส่วนรายการรายจ่ายและการออมที่ผู้ใช้บันทึกไว้จะยังคงอยู่

## ตัวเลขเริ่มต้น

เมื่อเปิดหน้าคำนวณเงินเดือนครั้งแรก ระบบจะโหลดตัวอย่างให้ตรงกับภาพต้นฉบับ:

- เงินเดือนพื้นฐาน `19,193.00 บาท`
- วันฐาน `23 วัน`
- ชั่วโมงทำงาน `8 ชั่วโมง/วัน`
- OT วันปกติ `1,152 นาที`
- รายได้เพิ่มเติมรวม `4,807.00 บาท`
- รายได้รวม `27,004.12 บาท`
- รายการหักรวม `2,803.51 บาท`
- เงินสุทธิ `24,200.61 บาท`

ตัวอย่างการแบ่งเงินสุทธิ:

- ค่าใช้จ่ายจำเป็น 50% = `12,100.31 บาท`
- ความสุขส่วนตัว 30% = `7,260.18 บาท`
- การออมและการลงทุน 20% = `4,840.12 บาท`

## สูตรเงินเดือนหลัก

```text
เงินได้ต่อวัน     = เงินเดือนพื้นฐาน ÷ จำนวนวันฐาน
เงินได้ต่อชั่วโมง = เงินได้ต่อวัน ÷ ชั่วโมงทำงานต่อวัน
เงินได้ต่อนาที    = เงินได้ต่อชั่วโมง ÷ 60
ค่า OT            = จำนวนนาที OT × เงินได้ต่อนาที × ตัวคูณ OT
รายการหักรวม      = รายการหักที่เพิ่มเอง + กองทุน + ประกันสังคม + ลาไม่รับค่าจ้าง + มาสาย
เงินสุทธิ          = รายได้รวม − รายการหักรวม
```

## วิธีเปิดใช้งานในเครื่อง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้โดยตรง หรือเปิดผ่าน Local Server เช่น:

```bash
python -m http.server 8000
```

จากนั้นเปิด `http://localhost:8000`

## วิธีนำขึ้น GitHub Pages

1. สร้าง Repository ใหม่ใน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ระดับบนสุดของ Repository
3. Commit และ Push ขึ้น GitHub
4. เข้า `Settings` → `Pages`
5. ในส่วน `Build and deployment` เลือก `Deploy from a branch`
6. เลือก Branch `main` และ Folder `/ (root)`
7. กด `Save` แล้วรอ GitHub สร้าง URL เว็บไซต์

โครงสร้างไฟล์สำคัญ:

```text
index.html
finance-50-30-20.html
style.css
app.js
README.md
.nojekyll
preview.png
preview-finance.png
```

ต้องวาง `finance-50-30-20.html` ไว้ระดับเดียวกับ `index.html` เพื่อให้ปุ่มเชื่อมต่อระหว่างสองหน้าทำงานถูกต้อง

## การเก็บข้อมูล

ข้อมูลของทั้งสองหน้าถูกเก็บใน `localStorage` ของเบราว์เซอร์บนอุปกรณ์ที่ใช้งาน ไม่ได้ส่งขึ้น GitHub หรือระบบภายนอก โดยแต่ละหน้ามีชุดข้อมูลของตัวเอง และหน้าคำนวณเงินเดือนจะส่งเฉพาะเดือน ยอดรายได้รวม ยอดหัก และเงินสุทธิไปยังหน้าวางแผนเมื่อผู้ใช้กดปุ่ม

ควรกด **สำรอง JSON** เป็นระยะ เพราะหากล้างข้อมูลเว็บไซต์ เปลี่ยนเบราว์เซอร์ หรือเปลี่ยนอุปกรณ์ ข้อมูลเดิมจะไม่ย้ายตามโดยอัตโนมัติ

> หมายเหตุ: ระบบนี้เป็นเครื่องมือช่วยคำนวณตามข้อมูลและอัตราที่ผู้ใช้กำหนด ควรตรวจสอบผลกับนโยบายบริษัท เอกสารเงินเดือน และข้อกำหนดที่ใช้งานจริงก่อนนำไปใช้อ้างอิง
